# Matt's Crosshair

A desktop crosshair overlay for Windows written in Rust.

## Usage

1. Click **Code** -> **Download ZIP** and extract the folder.
2. Run `target\release\matts_crosshair.exe` (optionally create a desktop shortcut).
3. Use the system tray icon to open settings or exit.

If Windows SmartScreen blocks the first launch, click **More info** -> **Run anyway**.

## Anti-Cheat

This app renders a standard transparent desktop overlay and does not read, modify, or hook into game memory. Always check a game's terms of service before using third-party overlays.

## Build from Source

Requires [Rust](https://rustup.rs/).
